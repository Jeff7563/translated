# ห้องสมองกลาง: ความรู้สำหรับทำระบบแปลหน้าเว็บให้เป็นธรรมชาติ

อัปเดต: 1 พ.ย. 2026

## เป้าหมาย
แปลหน้าเว็บแบบเรียลไทม์ ได้ทุกคู่ภาษา (อังกฤษ→ไทย, จีน→ไทย, ไทย→จีน, อังกฤษ→เยอรมัน ฯลฯ)
โดยหัวใจคือ **แปลให้ตรงจริตคนอ่าน** ไม่แปลตรงตัวจนแข็ง ใช้ภาษาที่คนพูดจริงตามบริบท
กรณีใช้งานแรก: อ่านการ์ตูนบนเว็บภาษาอังกฤษ

## ทำไม Google Translate ถึงแปลแข็ง
- เป็นเครื่องแปลแบบประโยคต่อประโยค ไม่รู้บริบททั้งหน้า ไม่รู้ว่าใครพูดกับใคร
- ไม่รู้ประเภทเนื้อหา (การ์ตูน แชท ข่าว) จึงใช้ระดับภาษาเดียวกันหมด
- ไม่จำชื่อตัวละคร/ศัพท์เฉพาะ ทำให้แปลไม่คงที่
ทางแก้: ใช้ **LLM** (Claude, GPT, Gemini, DeepSeek, หรือโมเดลรันเองผ่าน Ollama) พร้อม prompt ที่บอกบริบท สไตล์ และอภิธานศัพท์

## หลักการแปลให้ "ตรงจริต" (ส่วนสำคัญที่สุด)
1. **ส่งบริบท ไม่ใช่ทีละประโยค**: รวมหลายย่อหน้า/ทั้งตอนส่งไปพร้อมกัน ให้โมเดลรู้เรื่องราว
2. **บอกประเภทและโทน**: เช่น "การ์ตูนแอ็กชัน วัยรุ่น ภาษาพูด" vs "บทความวิชาการ"
3. **อภิธานศัพท์ (glossary)**: ชื่อตัวละคร ท่าไม้ตาย ศัพท์เฉพาะ ให้แปลคงที่ทุกตอน
4. **ข้อมูลตัวละคร**: เพศ อายุ นิสัย ใครพูดกับใคร เพื่อเลือกสรรพนาม/คำลงท้ายภาษาไทย (กู/มึง, ผม/ครับ, ฉัน/ค่ะ, เค้า/ตัวเอง)
5. **กฎเฉพาะภาษาปลายทาง** เช่น ภาษาไทย: ไม่ใส่ประธานทุกประโยค, ใช้คำลงท้าย (นะ, สิ, เหรอ, ว่ะ), แปลสำนวนเป็นสำนวนไทยที่ความหมายเท่ากัน ไม่แปลคำต่อคำ, คำอุทาน/เสียงประกอบใช้แบบไทย
6. **จำบริบทข้ามหน้า**: เก็บสรุปเรื่อง + glossary ไว้ใช้ตอนถัดไป
7. **ให้ผู้ใช้แก้คำแปลได้** แล้วนำไปเป็นตัวอย่าง (few-shot) ครั้งหน้า

ตัวอย่าง prompt แกนหลัก:
```
You are a professional {source}→{target} translator for {genre}.
Translate so it reads like it was originally written in {target} by a native speaker:
natural spoken register, keep tone/emotion, adapt idioms and jokes, never word-for-word.
Characters: {character notes}. Glossary (must use): {glossary}.
Story so far: {summary}.
Return JSON array matching input ids.
```

## สถาปัตยกรรมที่แนะนำ
```
Browser extension (WXT, Chrome/Edge/Firefox)
 ├─ Content script: เก็บข้อความบนหน้า (และรูปการ์ตูน) แบ่งเป็นก้อน
 ├─ แสดงผล: แทนที่ข้อความ หรือแสดงสองภาษา / ทับบอลลูนในรูป
 ├─ Background: เรียก LLM (Claude/GPT/Gemini/Ollama) + cache คำแปล
 └─ Settings: ภาษา คู่ภาษา โทน glossary ต่อเว็บ/ต่อเรื่อง
(ทางเลือก) Backend Python: manga-image-translator สำหรับลบ/วาดตัวอักษรในรูปแบบเนียน
```
