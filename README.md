# TranslateT

ส่วนขยายเบราว์เซอร์ (Chrome / Edge / Brave) ที่แปลหน้าเว็บด้วย AI ให้อ่านลื่นเหมือนคนเขียนเอง ไม่แข็งแบบแปลตรงตัว
แปลได้ทุกคู่ภาษา และแปลตัวหนังสือในรูปการ์ตูน (บอลลูนคำพูด) ได้ด้วย

## ทำอะไรได้
- แปลข้อความทั้งหน้า รวมถึงข้อความที่โหลดเพิ่มทีหลัง (เลื่อนลงแล้วแปลต่ออัตโนมัติ)
- แปลบอลลูนในรูปการ์ตูน/เว็บตูน แล้ววางคำแปลทับบนรูป (คลิกบอลลูนเพื่อดูต้นฉบับ)
- ส่งบริบทของหน้าไปด้วย ให้ AI รู้ว่าเรื่องเป็นยังไง ใครพูดกับใคร
- ตั้งประเภทเนื้อหา น้ำเสียง อภิธานศัพท์ (ชื่อตัวละคร ศัพท์เฉพาะ) และข้อมูลตัวละครได้
- เลือก AI ได้: Claude, Gemini, OpenAI หรือเจ้าที่เข้ากันได้ (OpenRouter, DeepSeek, Ollama รันบนเครื่องฟรี)
- จำคำแปลไว้ (cache) ไม่เสียเงินแปลซ้ำ
- ตั้งให้แปลอัตโนมัติเฉพาะเว็บที่เลือก, คีย์ลัด Alt+T, คลิกขวาที่รูปเพื่อแปลรูปเดียว

## ติดตั้ง
1. ดาวน์โหลดโค้ด (หรือ `git pull` ใน `D:\Work\trandslateT`)
2. เปิด `chrome://extensions` แล้วเปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `extension`
4. คลิกไอคอน TranslateT > **ตั้งค่าเพิ่มเติม** เลือก AI แล้วใส่ API key
   - Claude: สร้าง key ที่ console.anthropic.com
   - Gemini: สร้าง key ที่ aistudio.google.com (มีโควต้าฟรี)
5. เปิดเว็บการ์ตูน กดไอคอน > **แปลหน้านี้** (หรือกด Alt+T)

## อ่านบนมือถือ (iPhone / Android)

มือถือลงส่วนขยายไม่ได้ เลยมี **TranslateT Reader** เป็นเว็บเล็ก ๆ ที่รันบนคอม มือถือเปิดผ่านเบราว์เซอร์ วางลิงก์ตอนการ์ตูน แล้วอ่านพร้อมคำแปลทับบอลลูน คอมเป็นคนเปิดเว็บการ์ตูน (ผ่าน Chrome/Edge ที่มีในเครื่อง) และแปลด้วย Ollama

1. ติดตั้ง [Node.js](https://nodejs.org) (LTS) และ Ollama พร้อมโมเดลที่ดูรูปได้ เช่น `ollama pull qwen2.5vl:7b`
2. ดับเบิลคลิก `reader/start.bat` (ครั้งแรกจะติดตั้งของที่ต้องใช้เอง) หน้าต่างจะแสดงลิงก์ เช่น `http://192.168.1.10:8787/?k=...`
3. เปิดลิงก์นั้นบนมือถือ (ต้องมี `?k=...` ต่อท้ายด้วย) แล้วกดแชร์ > "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนเหมือนแอป
4. อยู่นอกบ้าน: ลง [Tailscale](https://tailscale.com/download) ทั้งคอมและมือถือ ล็อกอินบัญชีเดียวกัน แล้วใช้ลิงก์ที่ขึ้นต้นด้วย `100.` แทน

ปรับโมเดลหรือสไตล์การแปล: คัดลอก `reader/config.example.json` เป็น `reader/config.json` แล้วแก้ อย่าเปิดพอร์ต 8787 หรือ 11434 ออกอินเทอร์เน็ตตรง ๆ ที่เราเตอร์

## โครงสร้างโค้ด
```
extension/
  manifest.json
  popup.html/.js      หน้าต่างเล็กตอนกดไอคอน
  options.html/.js    หน้าตั้งค่า
  src/prompt.js       พรอมต์หัวใจของการแปลให้เป็นธรรมชาติ (กฎภาษาไทยอยู่ที่นี่)
  src/providers.js    เรียก Claude / Gemini / OpenAI
  src/background.js   คิวแปล, แคช, ตัดรูปเว็บตูนยาวเป็นท่อน
  src/content.js      เก็บข้อความ/รูปในหน้า และแสดงคำแปล
docs/KNOWLEDGE.md     ความรู้และโอเพนซอร์สที่ศึกษามา
```

## ข้อจำกัดตอนนี้
- ตำแหน่งบอลลูนขึ้นกับความแม่นของ AI (Gemini มักวางกรอบแม่นสุด)
- บอลลูนที่ถูกตัดคร่อมรอยต่อของรูปเว็บตูนยาวอาจแปลเป็นสองชิ้น
- รูปบางเว็บที่กันการโหลดข้ามเว็บอาจแปลไม่ได้
- แปลรูปใช้โทเคนมากกว่าข้อความ ควรดูค่าใช้จ่ายของผู้ให้บริการ
